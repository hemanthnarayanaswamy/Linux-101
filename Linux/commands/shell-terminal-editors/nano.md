# `nano`

`nano` is a simple terminal text editor.

Open a file:

```bash
nano file.txt
sudo nano /etc/hosts
```

Common shortcuts:

| Shortcut | Meaning |
|:---------|:--------|
| `Ctrl+O` | Write/save file |
| `Enter` | Confirm filename while saving |
| `Ctrl+X` | Exit |
| `Ctrl+W` | Search |
| `Ctrl+K` | Cut line |
| `Ctrl+U` | Paste line |

`nano` is useful for quick edits. For advanced terminal editing, learn enough `vim` to survive.
