## Pipes and Redirections 

Pipes and redirection are powerful features in Unix that allow you to control the flow of data between commands and files.

## Regular Expressions Intro 
Regular expressions (regex) in Linux are powerful patterns used to search, match, and manipulate text, most commonly with tools like grep, sed, and awk. 

[REGEX](../concepts/text-patterns/regex.md)

## Non-Interactive Editing Commands 

#### The `grep` command
The grep command (Global Regular Expression Print) is a powerful Linux/Unix utility for searching text patterns in files or output streams.
- It supports regular expressions, multiple search options, and works efficiently with large datasets.

[grep](../commands/text-processing/grep.md)

#### The `sed` command
`sed`, short for *Stream Editor*, is a powerful text-processing tool in Linux/Unix systems. It is primarily used for performing basic and advanced text transformations on an input stream.

###### Key Features
* **Text Substitution**: Replace specific patterns in text using regular expressions.
* **Text Deletion**: Remove lines or patterns from a file.
* **Text Insertion**: Add text before or after specific lines.
* **Batch Processing**: Process multiple files or streams efficiently.

[sed](../commands/text-processing/sed.md)

#### The `awk` command
**AWK** is a powerful text-processing tool and scripting language used for pattern scanning, data manipulation, and generating reports.

[awk](../commands/text-processing/awk.md)

#### `find` 
**find**: Searches for files/directories based on criteria (name, type, size, date, etc.).

[find](../commands/file-search-navigation/find.md)

#### The `xargs` command
**xargs**: Takes input (usually from stdin) and builds/executed commands with it.

Combining **xargs** with other commands, it becomes highly efficient for batch-processing files.

[xargs](../commands/text-processing/xargs.md)

#### The `sort` command
The sort command in Unix/Linux is used to sort lines in text files.

[sort](../commands/text-processing/sort.md)

#### The `tr` command
The `tr` command in UNIX is a command line utility for translating or deleting characters.

[tr](../commands/text-processing/tr.md)

#### The `diff` command
Its primary purpose is to compare the contents of two files and display the differences between them. The command provides a comprehensive way to highlight changes, additions, and deletions in a clear and readable format.

[diff](../commands/text-processing/diff.md)

#### The `wc` command
The wc (word count) command in Linux is used to count lines, words, characters, and bytes in files or from standard input.

[word count](../commands/text-processing/wc.md)
